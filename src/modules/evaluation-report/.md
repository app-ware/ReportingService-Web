# Evaluation Report Service Migration 

## 1. Overview 🎯

This project's goal is to migrate a legacy report generation service from a WCF and Crystal Reports stack to a modern, scalable, and maintainable solution using **Nest.js**, **Playwright**, and **Handlebars**.

The service generates a complex, multi-page "Child Evaluation Report" PDF. The report's content, structure, and styling are highly dynamic and configured by users through a web application.

## 2. Technology Stack 🛠️

* **Backend Framework:** **Nest.js** - A progressive Node.js framework for building efficient and scalable server-side applications.
* **Database Driver:** **node-mssql (`mssql`)** - A robust SQL Server driver for Node.js. Database interactions are performed via direct SQL queries and stored procedure execution.
* **PDF Generation:** **Playwright** - For rendering an HTML page in a headless browser and exporting it as a high-fidelity PDF.
* **HTML Templating:** **Handlebars** - To dynamically generate the report's HTML structure from a JSON data object.
* **Database:** **MS SQL Server** - The existing database that will be used as the data source.

---

## 3. Core Logic & Architecture 🏗️

The new service will follow a simple, robust workflow:

1.  **API Request:** A client sends a `GET` request to the Nest.js API endpoint. Guards like `JwtAuthGuard` and `CenterAccessGuard` secure the endpoint.
2.  **Data Aggregation:** The `EvaluationReportsService` is injected with the `mssql.ConnectionPool` and executes the existing `[dbo].[getTermEvaluationReportDataByChild]` stored procedure to get the main report data as a flat list. Additional queries are made to fetch report settings and styling variants.
3.  **Tree Construction:** A crucial step is to transform the flat list of nodes returned by the stored procedure into a nested, tree-like JSON object. This is done efficiently in memory to make it easy for Handlebars to render.
4.  **HTML Rendering:** The aggregated JSON object is passed to a `PdfService`, which uses Handlebars to compile a dynamic `.hbs` template into a complete HTML string.
5.  **PDF Generation:** The `PdfService` passes the final HTML to a headless Playwright browser instance, which renders the page and generates a PDF buffer.
6.  **API Response:** The controller streams the PDF buffer back to the client with the `application/pdf` content type.

## 4. API Endpoint Design 📡

The endpoint will be defined in `evaluation-reports.controller.ts` and will match your existing patterns.

`GET /evaluation-reports/download`

#### Decorators & Guards:

* `@UseGuards(JwtAuthGuard, CenterAccessGuard)`: Ensures the user is authenticated and has access to the required center.
* `@User()`: A custom decorator to extract user and center information from the JWT payload.
* `@ResponseMessage()`: A custom decorator to set a standard success message.

#### Query Parameters:

A `GenerateEvaluationReportDto` will be used to validate the incoming query parameters.

| Parameter | Type   | Description                                                               | Example         |
| :-------- | :----- | :------------------------------------------------------------------------ | :-------------- |
| `childId` | number | **Required.** The ID of the child for whom the report is generated.       | `24738`         |
| `reportId`| number | **Required.** The ID of the evaluation report configuration to use.       | `3`             |
| `terms`   | string | **Required.** A comma-separated string of term IDs to include as columns. | `'8,9'`         |
| `approve` | string | Optional. If `'1'`, the generated file link is saved to the database.     | `'1'`           |

#### Example Controller Method:

```typescript
// src/evaluation-reports/evaluation-reports.controller.ts
@ResponseMessage('Successfully generated evaluation report.')
@UseGuards(JwtAuthGuard, CenterAccessGuard)
@Get('download')
@HttpCode(HttpStatus.OK)
async generateReport(
  @User('centerId', ParseIntPipe) centerId: number,
  @Query() reportDto: GenerateEvaluationReportDto,
  @Res() res: Response,
): Promise<void> {
  const pdfBuffer = await this.evaluationReportsService.generatePdf(centerId, reportDto);

  res.setHeader('Content-Type', 'application/pdf');
  res.setHeader('Content-Disposition', `attachment; filename=evaluation_report.pdf`);
  res.send(pdfBuffer);
}
